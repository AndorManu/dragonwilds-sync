# Support

**Something broke?** Open an [issue](https://github.com/AndorManu/worldsync/issues/new) with:

1. What you did (Play / Save now / Join / Update…)
2. What you expected and what happened instead
3. The log: in the app, *Settings → Open log folder*, attach the newest `.log`
4. Which game, and its version (Steam → the game → Properties → Updates) and app version (About page)

Saves are never deleted by the app - every overwrite is backed up first under
*world menu → Backups*, and the automatic copies live in
`%APPDATA%\WorldSync\backups\`. If a save looks wrong, restore from
there before anything else.

**Questions, ideas, "does it work with…"** → [Discussions](https://github.com/AndorManu/worldsync/discussions).
